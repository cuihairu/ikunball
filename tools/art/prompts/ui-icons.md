# UI 图标提示词

## 目标

生成按钮、图标、入口图等基础 UI 资源概念稿。

## 开始按钮

```text
A playful mobile game start button, sporty basketball theme, rounded shape, bright colors, simple icon style, transparent background
```

## 复活按钮

```text
A casual mobile game revive button, reward video ad theme, sporty and funny style, bright readable icon, transparent background
```

## 排行榜图标

```text
A leaderboard icon for a funny basketball mini game, cute sporty style, simple clean shape, transparent background
```

## 命中图标

```text
A hit effect icon for a basketball mini game, energetic burst shape, bright sporty color palette, transparent background
```

## 使用建议

- UI 图标优先清晰，不要太写实
- 尽量保持边缘干净
- 后续通常还要手工修边和统一尺寸
