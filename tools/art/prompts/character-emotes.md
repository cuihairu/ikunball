# 表情提示词

## 目标

围绕同一只小鸡快速产出四类核心表情：

- 平静
- 开心
- 上头
- 破防

## 平静

```text
The same yellow basketball chick mascot, calm expression, neutral eyes, slight smile, idle pose, clean mobile game sprite style, transparent background
```

## 开心

```text
The same yellow basketball chick mascot, happy expression, bright eyes, excited smile, cheerful sports vibe, clean outline, transparent background
```

## 上头

```text
The same yellow basketball chick mascot, overexcited meme face, intense eyes, confident grin, hot streak energy, basketball game combo moment, transparent background
```

## 破防

```text
The same yellow basketball chick mascot, defeated meme face, shocked and broken expression, slightly messy pose, funny failure mood, transparent background
```

## 使用建议

- 先固定主角基准图
- 每次只替换“expression / mood / pose”部分
- 保持主体比例和配色不变
