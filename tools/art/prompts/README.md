# prompts

这里放 AI 出图提示词模板。

当前分类：

- `character-base.md`：主角小鸡基础设定
- `character-emotes.md`：表情扩展
- `character-actions.md`：动作和投篮姿势
- `backgrounds.md`：场景背景
- `promo-images.md`：宣传图和封面图
- `ui-icons.md`：UI 图标和按钮资源
- `variables.md`：常用变量表
- `character-template.md`：角色通用模板
- `background-template.md`：背景通用模板
- `batch-plan.md`：批量出图顺序

建议用法：

1. 先用 `character-base.md` 定主角
2. 再用 `variables.md` 和 `character-template.md` 固定变量
3. 再用 `character-emotes.md` 和 `character-actions.md` 扩展资产
4. 最后生成背景、宣传图和 UI 图
