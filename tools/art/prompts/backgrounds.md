# 场景背景提示词

## 目标

先出能支撑小游戏氛围的简单背景，不追求大场景叙事。

## 首页背景

```text
A playful basketball mini game background, bright sky, fun court atmosphere, light graphic shapes, cheerful sporty colors, simple mobile game background, no characters, no text
```

## 对局背景

```text
A clean cartoon basketball court background for a mobile mini game, readable composition, bright sporty palette, simple shapes, no characters, no text
```

## 结果页背景

```text
A celebratory casual game result screen background, sporty and funny atmosphere, bright shapes, clean mobile game design, no characters, no text
```

## 使用建议

- 背景尽量简洁
- 不要抢过角色和 UI
- 留出中间和上方区域给 HUD
