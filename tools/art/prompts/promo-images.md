# 宣传图提示词

## 目标

生成适合小游戏封面、商店图、活动图的高冲击画面。

## 封面图

```text
A funny yellow chick basketball mascot as the hero of a mini game cover, dynamic action, bold colors, meme energy, playful sports vibe, polished promotional illustration, highly readable composition
```

## 连击高光图

```text
A yellow chick basketball mascot in a hot streak moment, dramatic combo feeling, exaggerated expression, energetic sports action, vibrant promo art, mobile game advertisement style
```

## 失败搞笑图

```text
A funny yellow chick basketball mascot failing a shot in a meme way, chaotic but cute, exaggerated expression, humorous promotional art, mobile mini game style
```

## 使用建议

- 宣传图可以比游戏内资源更夸张
- 允许更强光效和构图张力
- 但主角脸和篮球元素必须清楚
