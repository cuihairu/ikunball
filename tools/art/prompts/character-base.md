# 主角基础提示词

## 目标

先定一只主角小鸡的统一外观，后续所有动作、表情、皮肤都围绕这一版扩展。

## 基础提示词

```text
A cute yellow chick mascot for a casual mobile basketball game, round body, tiny wings, short legs, expressive face, sporty headband, holding a basketball, bold clean outline, bright saturated colors, simple readable shape design, meme energy, mobile game art style, transparent background
```

## 加强版

```text
A highly recognizable yellow chick mascot, designed for a funny basketball mini game, cute but chaotic, round silhouette, orange beak, orange feet, sporty wristband, basketball theme, exaggerated facial expression, thick outline, flat shading, polished mobile game character sheet style, transparent background, centered composition
```

## 负面方向

不希望出现：

- realistic feathers
- detailed background
- complex lighting
- horror expression
- human hands
- extra limbs
- text watermark

## 固定设定建议

每次出图都尽量重复这些元素：

- yellow chick
- round body
- orange beak
- sporty accessory
- basketball
- bold outline

## 第一批建议产出

- 主立绘正面
- 主立绘侧面
- 持球站姿
- 默认表情
