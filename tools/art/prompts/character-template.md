# 角色通用模板

## 模板

```text
The same {character}, {body_shape}, {beak_color}, {accessory}, {emotion} expression, {pose}, {outline}, {style}, {quality}, {background_mode}
```

## 示例 1：默认站姿

```text
The same yellow basketball chick mascot, round body, orange beak, sporty headband, calm expression, idle pose, bold clean outline, clean mobile game sprite style, clean readable, transparent background
```

## 示例 2：命中庆祝

```text
The same yellow basketball chick mascot, round body, orange beak, sporty headband, happy expression, celebrating a successful shot, bold clean outline, clean mobile game sprite style, polished, transparent background
```

## 示例 3：破防失败

```text
The same yellow basketball chick mascot, round body, orange beak, sporty headband, broken expression, failed shot reaction, bold clean outline, clean mobile game sprite style, high clarity, transparent background
```
